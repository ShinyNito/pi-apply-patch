# @shinynito/apply-patch-node

Rust-powered Codex-style `apply_patch` engine for Node.js. Matching is exact and SIMD-accelerated; a mismatch fails immediately without whitespace, Unicode, or TypeScript fallback behavior.

This package is the runtime engine used by `@shinynito/pi-apply-patch`. It bundles native binaries for supported macOS, Linux, and Windows targets.
